# Smart Health Assistant

## Project Overview

Smart Health Assistant is a React-based web application designed to help users monitor and improve their daily health habits through an interactive and user-friendly platform.

The application provides basic symptom-based health guidance along with tools for tracking water intake, sleep patterns, daily habits, and medicine schedules. It aims to encourage preventive healthcare by helping users build healthy routines and stay aware of their well-being.
